# 해솔네컷 — GitHub Pages 배포

이 프로젝트는 별도 패키지 설치 없이 작동하는 반응형 할로윈 네 컷 사진 부스입니다.

## 기능
- 카메라로 사진 4장 순서대로 촬영(3초 카운트다운)
- 할로윈 스티커 추가·드래그·크기 변경·삭제
- 1200 × 1480 PNG 결과 저장
- 첨부 레퍼런스를 사용한 정적인 가장자리 반짝임 배경
- 사진 업로드 기능, 사진 선택 영역, 단계 안내 바 없음

## 배포
1. 이 폴더의 `index.html`, `README.md`, `.nojekyll`을 GitHub 저장소 루트에 업로드합니다.
2. Settings → Pages → Build and deployment에서 Deploy from a branch를 선택합니다.
3. `main` / `/(root)`를 선택한 뒤 Save합니다.
4. `https://사용자명.github.io/저장소명/`을 열어 확인합니다.

카메라는 HTTPS 또는 localhost 환경에서 권한 허용 후 사용할 수 있습니다.

- 카메라 시작 / 촬영하기 / 꾸미러 가기 버튼을 모든 화면에서 한 줄로 배치했습니다.
